# Dashboard

React + Vite + Tailwind + Recharts. Talks to the bot API (`src/api/`).

```
cd dashboard
npm install
npm run dev        # http://localhost:5173 — log in with DASHBOARD_PASSWORD
```

Deployed to GitHub Pages by `.github/workflows/dashboard.yml` on every push to `main`
that touches `dashboard/`. The bot address can be changed on the login screen ("Bot address").
